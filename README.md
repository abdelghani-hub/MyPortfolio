# Abdelghani Ait Tamghart — Portfolio

Responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. Includes dark/light mode with saved preference, scroll reveal animations with reduced-motion support, selected projects, professional experience, contact links, and a downloadable CV.

## Run locally

Open `index.html` directly, or serve this directory:

```sh
python3 -m http.server 8000
```

Visit http://localhost:8000. Clipboard access works on localhost or HTTPS; other contexts show the contact fallback.

## Deploy

No installation or build step is required. Upload `index.html`, `style.css`, `script.js`, and `Abdelghani-Ait-Tamghart-CV.pdf` together to any static web host. Use the repository root as the publish directory and leave the build command empty.

## Edit

- `index.html`: content, project links, experience, and contact details.
- `style.css`: colors, typography, responsive layouts, and animations.
- `script.js`: theme persistence, reveal observer, and copy-email interaction.
- `Abdelghani-Ait-Tamghart-CV.pdf`: downloadable resume; preserve the filename or update both download links.
